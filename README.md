# Audio Output Switcher

Top-bar aux-jack icon listing only connected sound outputs. Click to switch; scroll to change volume.

GNOME Shell extension (45–50).

## Install

```sh
git clone https://github.com/voidrlm/gnome-audio-output-switcher.git ~/.local/share/gnome-shell/extensions/audio-output@arjun
gnome-extensions enable audio-output@arjun
```

Log out and back in (Wayland) for GNOME to discover it.
